# SEO, Sitemap and Link Previews Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Search engines and link previews see real pages for Macro Genie's fixed pages and each live community recipe, and the admin Money tab shows what the new server-built pages cost on Netlify.

**Architecture:**
- **Fixed pages** get their own HTML file at build time (`dist/seo/`, reached through `dist/_redirects` rewrites), with per-page title, description and Open Graph tags.
- **`/community/:id` and `/sitemap.xml`** are Netlify functions. Their responses are cached on Netlify's CDN under cache tags, and the server clears those tags when a post's visibility changes.
- **Head tags:** a small pure helper in `src/seo/head.js` writes them. The Vite build step and the server both use it.
- **Money tab:** each function run (a cache miss) adds to a `page_builds` counter, which the Money tab turns into an estimate.

**Tech Stack:** Svelte 5 SPA + Vite 7, Netlify Functions (Node ESM, `config.path`), `@netlify/functions` `purgeCache`, Postgres (Neon; `@netlify/database-dev` in tests), `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-14-seo-design.md`

## Global Constraints

- Site origin for canonical/OG URLs: `https://macro-genie.com` (constant `SITE` in `src/seo/pages.js`).
- Indexed: `/`, `/foods`, `/builder`, `/community`, `/help`, every `/help/<guide slug>`, `/terms`, `/refunds`, `/privacy`, `/contact`, and live recipe posts at `/community/<id>`.
- Never indexed: forum threads (`kind = 'thread'`), posts whose status isn't `live`, `/admin`, `/api/`, `/credits`, `/recipes`.
- Recipe pages show name, description, meal type, servings, per-serving calories/protein/carbs/fat, ingredients, steps, author display name, and date. They never show likes or comments.
- All post text is HTML-escaped. JSON-LD has `<` written as `<`. Every string replacement into the template uses a replacer *function*, never a replacement string, so `$&`/`$1` in user text stays literal.
- Recipe page and sitemap cache headers: `Netlify-CDN-Cache-Control: public, durable, s-maxage=86400, stale-while-revalidate=604800`; `Cache-Control: public, max-age=0, must-revalidate`; `Netlify-Cache-Tag: post-<id>,posts` (sitemap: `sitemap`). Fallback/error responses use `Cache-Control: no-store` and no CDN header.
- Purges happen only in the real Netlify runtime: skip when `process.env.MACRO_GENIE_LOCAL` is set or `process.env.NETLIFY_PURGE_API_TOKEN` is missing. `purgePost` never throws.
- Netlify estimate: `CREDITS_PER_GB_HOUR = 10`, `CREDITS_PER_10K_REQUESTS = 2`, `CENTS_PER_CREDIT = 1` (Netlify pricing April 2026; the user's top-up is $5 for 500 credits). Function memory is 1 GB. The estimate is shown for information only and is **never** part of `netCents`.
- A failed `page_builds` upsert is logged and ignored.
- Match the surrounding code: short "why" comments, plain JS ESM, Svelte 5 runes. Commit after each task. Never push.

## Review Focus

1. **Hostile post text:** a name or step such as `</script><script>alert(1)</script>`, `"><img onerror=…>` or `$&` must stay inert and literal in the `<title>`, the meta tags, the body and the JSON-LD. Task 2 tests all three shapes.
2. **Bad ids:** `/community/abc`, `/community/0`, `/community/99999999999999999999` and `/community/12.5` must give the plain page with `noindex`, never a 500. Task 3 tests these.
3. **Database down:** the recipe page falls back to the plain page with `no-store`, and `/sitemap.xml` returns 503 with `no-store`. Neither is cached. Task 3 tests both.
4. **Every path that changes visibility clears the cache:** going live at creation, moderator approve/remove/suspend, removal by the poster, a moderator removing all of a user's content, and delete & ban. A failing purge never fails the action. Task 4 tests each path.
5. **The app still starts on a server-built page:** `#app` is emptied before mount, so content never shows twice. Task 1 changes `src/main.js`; the manual check covers it.

`src/seo/head.js`:

```js
// Head tags for search engines and link previews. Pure string work, shared
// by the build (fixed pages) and the server (community recipe pages).

const ENTITIES = { "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" };
export const esc = (value) => String(value ?? "").replace(/[&<>"']/g, (c) => ENTITIES[c]);

// Replacers are functions so "$&" or "$1" in someone's recipe name stays text.
export function withHead(template, { title, description, canonical, image, type = "website", noindex = false, extraHead = "" }) {
  const tags = [
    `<link rel="canonical" href="${esc(canonical)}" />`,
    `<meta property="og:site_name" content="Macro Genie" />`,
    `<meta property="og:type" content="${esc(type)}" />`,
    `<meta property="og:title" content="${esc(title)}" />`,
    `<meta property="og:description" content="${esc(description)}" />`,
    `<meta property="og:url" content="${esc(canonical)}" />`,
    `<meta property="og:image" content="${esc(image)}" />`,
    `<meta name="twitter:card" content="summary_large_image" />`,
    ...(noindex ? [`<meta name="robots" content="noindex" />`] : []),
    ...(extraHead ? [extraHead] : []),
  ].join("\n    ");
  return template
    .replace(/<title>[\s\S]*?<\/title>/, () => `<title>${esc(title)}</title>`)
    .replace(/<meta\s+name="description"[\s\S]*?\/>/, () => `<meta name="description" content="${esc(description)}" />`)
    .replace("</head>", () => `  ${tags}\n  </head>`);
}

export const withBody = (template, html) =>
  template.replace(`<div id="app"></div>`, () => `<div id="app">${html}</div>`);
```

```js
import { database } from "./db.js";

export const NO_STORE = { "Cache-Control": "no-store" };

// Netlify's CDN keeps the page until a purge of one of its tags, or a day.
// Browsers always ask the CDN again.
export const cacheHeaders = (tags) => ({
  "Netlify-CDN-Cache-Control": "public, durable, s-maxage=86400, stale-while-revalidate=604800",
  "Cache-Control": "public, max-age=0, must-revalidate",
  "Netlify-Cache-Tag": tags.join(","),
});

// The built index.html (with this deploy's hashed script names), fetched
// from the site itself once per function instance; under npm run dev it's
// Vite's page.
let template = null;
let loadTemplate = async (origin) => {
  const res = await fetch(`${origin}/index.html`);
  if (!res.ok) throw new Error(`index.html ${res.status}`);
  return res.text();
};
export function useTemplate(fn) {
  loadTemplate = fn;
  template = null;
}
export async function getTemplate(origin) {
  template ??= await loadTemplate(origin);
  return template;
}

export async function livePost(id) {
  const { rows } = await database().pool.query(
    `SELECT p.id, p.name, p.meal_type, p.recipe, p.created_at, a.display_name AS author
       FROM posts p JOIN accounts a ON a.id = p.account_id
      WHERE p.id = $1 AND p.kind = 'recipe' AND p.status = 'live'`,
    [id],
  );
  const r = rows[0];
  return r
    ? { id: Number(r.id), name: r.name, mealType: r.meal_type, recipe: r.recipe, createdAt: r.created_at, author: r.author, kind: "recipe", status: "live" }
    : null;
}

export async function liveRecipes() {
  const rows = await database().sql`
    SELECT id, created_at FROM posts WHERE kind = 'recipe' AND status = 'live' ORDER BY id`;
  return rows.map((r) => ({ id: Number(r.id), createdAt: r.created_at }));
}

// Adds one server-built page and its run time to this month, for the Money
// tab. Never throws: a lost count only makes the estimate a little low.
export async function recordPageBuild(ms) {
  try {
    await database().sql`
      INSERT INTO page_builds (month, builds, ms)
      VALUES (date_trunc('month', now() AT TIME ZONE 'UTC')::date, 1, ${Math.round(ms)})
      ON CONFLICT (month) DO UPDATE
        SET builds = page_builds.builds + 1, ms = page_builds.ms + EXCLUDED.ms`;
  } catch (error) {
    console.error("page_builds:", error.message);
  }
}
```

```js
// /community/<id> as a real page for search engines and link previews.
// Live recipes get their content and preview tags; anything else gets the
// app with noindex. The app then loads over it as usual.
export const config = { path: "/community/:id", method: "GET" };

const html = (body, headers) =>
  new Response(body, { headers: { "Content-Type": "text/html; charset=utf-8", ...headers } });

async function handler(request) {
  const started = performance.now();

  const id = /^[1-9]\d{0,14}$/.test(raw) ? Number(raw) : null; // ≤ 15 digits: a safe integer
  let template;
  try {
    template = await getTemplate(origin);
  } catch (error) {
    console.error("seo-post: template", error);
    return new Response("Try again in a moment.", { status: 503, headers: NO_STORE });
  }
```

```js
// After a post goes live, comes down or is deleted: its page and the
// sitemap are rebuilt on the next visit. Never throws; a missed purge
// leaves the old copy for a day at most.
export async function purgePost(ids) {
  const list = [ids].flat().map(Number).filter((n) => Number.isSafeInteger(n) && n > 0);
  if (!list.length) return;
  try {
    await purge([...list.map((id) => `post-${id}`), "sitemap"]);
  } catch (error) {
    console.error("purge:", error.message);
  }
}
```

```js
// Netlify's credit prices (April 2026) and what a credit costs this site
// ($5 for 500 in the owner's top-up). Functions run with 1 GB.
const CREDITS_PER_GB_HOUR = 10;
const CREDITS_PER_10K_REQUESTS = 2;
const CENTS_PER_CREDIT = 1;

// What the server-built SEO pages cost, estimated from their count and run
// time. Shown for information: the real Netlify dollars are the plan and
// top-ups typed in as fixed costs.
async function netlifyMonth(key) {
  const rows = await database().sql`
    SELECT builds, ms FROM page_builds WHERE month = ${`${key}-01`}`;
  const builds = Number(rows[0]?.builds ?? 0);
  const ms = Number(rows[0]?.ms ?? 0);
  const credits = round2((ms / 3_600_000) * CREDITS_PER_GB_HOUR + (builds / 10_000) * CREDITS_PER_10K_REQUESTS);
  return { builds, credits, cents: round2(credits * CENTS_PER_CREDIT) };
}
```
